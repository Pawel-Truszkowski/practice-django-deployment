## Uruchomienie aplikacji

1. Otwórz terminal i przejdź do katalogu projektu:
   ```bash
   cd /ścieżka/do/twojego/projektu/
   ```

2. Uruchom Docker Compose:
   ```bash
   docker compose up
   ```

3. Otwórz przeglądarkę pod adresem:
   ```text
   http://localhost/
   ```

4. Aby zatrzymać aplikację i usunąć kontenery:
   ```bash
   docker compose down
   ```
